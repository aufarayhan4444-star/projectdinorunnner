# projectdinorunnner
Game Dino Runner adalah game yang terinspirasi dari mini game bawaan Google Chrome, yaitu T-Rex Runner. Game aslinya muncul waktu koneksi internet putus, lalu kita bisa main dengan menekan tombol spasi. Nah, versi ini bukan game aslinya dari Google, tapi hasil buatan sendiri.
Cara mainnya sebenarnya simpel. Karakter dinosaurus berlari terus ke depan secara otomatis, dan tugas pemain hanya menghindari rintangan. Kalau ada kaktus di depan, dino harus melompat. Kalau ada burung terbang rendah, dino bisa menunduk atau melompat di waktu yang pas. Semakin lama bermain, kecepatan lari makin naik, jadi tingkat kesulitannya ikut naik. Skor dihitung dari seberapa jauh dino bertahan, dan kalau dino menabrak rintangan, permainan berakhir (game over) lalu pemain bisa mengulang dari awal.
